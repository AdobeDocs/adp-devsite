# Agent guidance

This repository provides the shared theme and blocks for the Adobe Developer Website.

- Read [GLOSSARY.md](GLOSSARY.md) before discussing or changing site behavior, and use its terms.
- When changing a block, check whether it is used by DevDocs, DevBiz, or both. Do not assume that its configuration is the same in both.
- Keep domain terminology in `GLOSSARY.md`: one- or two-sentence definitions of what a term *is*, project-specific terms only, and an `_Avoid_:` line for rejected synonyms.
- For local setup and contribution procedures, see [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
